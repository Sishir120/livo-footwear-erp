## 2. DETAILED SUMMARY OF GAPS & BLOCKED MODULES

### 2.1 The Three Backend-Only Modules (GAP-12, GAP-13, GAP-14)
The backend routes and database schemas for **General Factory Expenses**, **Fixed Assets**, and **Waste Scrap Management** are 100% written, migrated in Alembic revision `020`, and tested via `backend/tests/test_fixed_assets_waste_and_expenses.py`.  
However, they are completely inaccessible to users in the browser because:
1. `frontend/src/components/AppShell.tsx` contains no navigation items for them in `navItems`.
2. No React components exist for `FixedAssetsView.tsx`, `WasteManagementView.tsx`, or `FactoryExpensesView.tsx`.
3. To achieve client acceptance, these three lightweight views must be built and linked into the navigation sidebar.

### 2.2 The Automated Backup Gap (GAP-15)
While `backend/app/services/backup_service.py` contains functional backup and restore routines, it is currently dead code unless an administrator clicks the manual trigger button in the Settings modal or issues an HTTP POST to `/api/v1/backup/run`.  
- **Remediation:** A Linux systemd timer (`/etc/systemd/system/livo-backup.timer`) or lightweight internal scheduler (`APScheduler`) must be registered in `lifespan` to invoke `run_database_backup()` at 02:00 NPT daily.
